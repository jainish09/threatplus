Working Set Sizing: Scenario Comparison Matrix

Scenario 1: Working Set < Cache (Current State) OPTIMAL
  • Working Set: ~20.55 MB (13,105 events) fits entirely within 1,024 MB cache.
  • Disk I/O: 0 page swaps during random lookups.
  • Latency: Ultra-low (~0.84 ms / read).
  • Eviction Penalty: None. WiredTiger LRU remains idle.
Scenario 2: Working Set > Cache (Cache Thrashing) BOTTLENECK
  • Working Set: E.g., 2,000 MB exceeds 1,024 MB cache.
  • Disk I/O: High random disk seeks on every query miss.
  • Latency: 10x-50x spike due to NVMe/EBS disk reads.
  • Eviction Penalty: High eviction loops and CPU load.
